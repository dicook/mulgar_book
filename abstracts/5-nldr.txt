# 5-nldr abstract

This chapter presents non-linear dimension reduction (NLDR) methods. It starts
by reviewing the classical approaches multidimensional scaling, isomap
and local linear embedding. The second section describes two
contemporary methods, t-SNE and UMAP. Because NLDR can create 
inaccurate representations it is important to have methods that help 
to assess the structures presented in the low-dimensional representation. 
Section three explains how this can be done using interactively linked 
displays: one display shows the view provided by the NLDR, and
the second display that shows linear projections of the data using a tour. 
Users can select points in one display and they will be highlighted in both 
plots. To illustrate the workflow, the last section then walks through a more 
complex example.

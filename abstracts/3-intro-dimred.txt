# 3-intro-dimred abstract

This chapter sets up the concepts related to methods for reducing dimension
such as principal component analysis (PCA) and t-stochastic neighbour embedding
(t-SNE), and how the tour can be used to assist with these methods. The first
section introduces the concept of implicit dimensionality and how it can be
perceived in data visualisation. This works well in particular with linear
association between variables, where PCA can be used to reduce dimensionality.
However, visualisation can reveal any type of association, and it is important
to be aware of these patterns when using dimension reduction, especially in the
case of non-linear methods like t-SNE. The second section then shows how these
different types of patterns can be detected in high-dimensions using tour
visualisations.

# 3-intro-dimred abstract

This chapter introduces the concepts related to methods for reducing dimension, 
and how the tour can be used to assist. It begins with an explanation of implicit 
dimensionality, which is followed later with an explanation how the tour can be used to detect 
it and determine which variables contribute to reducing the space. There is an 
illustration of a range of different pairwise associations that might be 
detected when visualising data using projections, and how tours can be used to 
detect these.

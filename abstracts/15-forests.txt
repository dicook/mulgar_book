# 15-forests abstract

In this chapter tree based classification models are considered.
The chapter starts with an introduction to classification trees, and an
explanation of how visualisation of the data can help us understand if
a tree model is appropriate. It then gives a brief introduction into the
random forest algorithm and the particular outputs for this class of models
that can be used for interpretation. First it is demonstrated how the
votes matrix can be examined in a simples for any number of classes in the
data, and how this allows us to identify which classes are more often
confused, and for which observations the model gets confused between
multiple classes. Finally the chapter also shows how to use variable
importance measures to better explore for class differences, and how
class-wise importance measures can be particularly useful in this context.

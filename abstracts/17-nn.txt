# 17-nn abstract

This chapter introduces neural networks and deep learning, and how we can
examine this class of models. It starts with an overview of the model
definition, followed by an explanation of how such models can be set
up in practice. It is then described how multivariate visualisation allows
us to check the split of observations into training and test data, to see
if both sets are comparable. The chapter then shows how to fit a neural
network model, and how the model components can be extracted after fitting.
These are used to demonstrate how examining the work of different nodes in 
the hidden layer and the predictive probabilities of the model
can be help to uderstand it, and determine where it might be improved. 
A final section shows an application to a large dataset, to give a realistic 
view of how the ideas introduced on simpler problems can be applied in practice.

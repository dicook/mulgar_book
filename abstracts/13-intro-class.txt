# 13-intro-class abstract

This chapter gives an introduction to supervised classification. It first
describes what aspects beyond maximum classification accuracy we are typically
interested in. These are questions about the model that help us understand and
interpret the model, and to better understand how predictions are made and how
we can diagnose issues in a fitted model. It then explains the trade-off between
bias and variance, and shows examples to illustrate how this translates into
visualsations of fitted models. The final section shows how tour methods can be
used in this context. First it explains how to visualise the training data to
understand the shapes and boundaries, so that we can select an appropriate
model. Then, for the interpretation of a fitted model, it is explained how the
tour can be used to explore where missclassified points fall relative to the
class distributions, and how we can compute predictions on simulated points
across the data domain to explore the class boundaries in the model.

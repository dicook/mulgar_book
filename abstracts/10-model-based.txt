# 10-model-based abstract

This chapter describes how visualisation can be used to examine a mixture models
derived from model-based clustering. It first shows how this works in two
dimensions, by comparing different models using a score like the Bayesian
Information Criterion, and then showing the fitted model as variance-covariance 
ellipses around the cluster means. It also illustrates how to overlay this model
representation on the data together, first in two dimensions, and then extended i
nto the high-dimensional setting by using tour methods.

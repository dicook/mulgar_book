# 10-model-based abstract

This chapter describes how visualisation can be used to examine a mixture model
derived from model-based clustering. It first shows how this works in two
dimensions, by comparing different models using a score like the Bayesian
Information Criterion, and then showing the data together with a selected model
that can be visualised as variance-covariance ellipses around the cluster means.
This is then extended into the high-dimensional setting by using tour methods.

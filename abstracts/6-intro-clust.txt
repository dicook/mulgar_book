# 6-intro-clust abstract

This chapter introduces the concepts of cluster data and how the tour can be
used to assist with identifying clusters. It begins with an explanation of
cluster analysis and how we can define what a cluster is. Examples of data
structures that can impact cluster analysis are shown. It then introduces
different definitions to measure similarity between cases and discusses what
should be considered to select an appropriate metric. It finishes with examples
that illustrate how tours can be used to perceive clustering.

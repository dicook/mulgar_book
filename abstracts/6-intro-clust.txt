# 6-intro-clust abstract

This chapter introduces the concepts of cluster data and how the tour can be
used to assist with identifying clusters. It begins with an explanation of
cluster analysis and how we can define metrics based on what we clustering 
patterns we expect to be present. Examples of complication structures that 
can impact distance calculations that then affect the cluster analysis are 
shown. It finishes with examples that illustrate how tours can be used to 
perceive clustering.

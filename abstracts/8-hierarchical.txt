# 8-hierarchical abstract

This chapter introduces visualisation for hierarchical cluster analysis.
It starts with an overview of hierarchical clustering, and the summary of a
clustering result in a dendrogram, showing how the dendrogram can be overlayed
on a data plot. This is followed by an illustration of common patterns that can
confuse hierarchical cluster analysis, and how they can be diagnosed visually.
It finishes with an explanation of how we can use the tour to visualise the
dendrogram in high dimensions.
